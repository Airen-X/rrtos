启动流程（真实项目）

① 复位 Resetcortex-m-rt 入口，初始化 .data/.bss，使能 FPU
② 硬件初始化时钟（PWR/RCC）、GPIO、SysTick（1ms）
③ #[kernel::entry]kernel::init(KernelConfig) 设置运行时配置、初始化列表
④ 创建对象 + spawnstatic_*! 惰性初始化；kernel::spawn(任务)
⑤ start_scheduler创建空闲任务 + 定时器守护任务，选出首个任务
⑥ SVC → 首任务恢复 PSP，异常返回进入第一个任务
⑦ 调度循环SysTick tick → PendSV → 切换最高优先级任务

上下文切换（PendSV，最低优先级异常）

进入 PendSVmrs r0, psp；FPU 时 tst lr,#0x10 → 保存 s16-s31
保存现场stmdb r0!, {r4-r11}；str r0 → pxCurrentTCB.top_of_stack
临界区选任务BASEPRI=0x50 → vTaskSwitchContext：位图取最高就绪优先级，轮转同优先级
恢复现场新任务 top_of_stack → ldmia {r4-r11}（+s16-s31）；msr psp, r0
异常返回bx lr（EXC_RETURN=0xFFFFFFFD/ED → Thread + PSP）

SysTick 异常 → kernel::tick_handler()：tick 计数、延时双列表到期唤醒、必要时触发 PendSV； SVC 异常 → 首次启动把控制流交给第一个任务。二者由内核导出 PendSV_Handler/SVC_Handler（及 cortex-m-rt 短命名 PendSV/SVCall）。

任务控制块 TCB（对应 FreeRTOS tskTCB）

#[repr(C)]
pub struct Task {
    pub top_of_stack: *mut u32,        // ← 必须是第一个字段：PendSV/SVC 汇编直接按偏移 0 存取
    pub state_item: ListItem,          // 就绪列表（FIFO）/ 延时列表（按唤醒时刻升序）
    pub event_item: ListItem,          // 对象等待列表（值 = max_priorities-1-优先级 → 高优先级在前）
    pub priority: Priority,            // 当前优先级（可能被互斥锁继承提升）
    pub base_priority: Priority,       // 基本优先级
    pub mutexes_held: u32,             // 持有互斥锁计数（释放归零时恢复优先级）
    pub state: TaskState,              // Running / Ready / Blocked / Suspended / Deleted
    pub stack_base: *mut u8,
    pub stack_size: usize,
    pub entry: EntryFn,                // unsafe extern "C" fn(*mut ()) -> !
    pub param: *mut (),
    pub name: &'static str,
    pub blocked_on: *mut (),           // 互斥锁优先级继承链
    #[cfg(feature = "task-notification")]
    pub notification: u32,             // 任务通知值
    #[cfg(feature = "task-notification")]
    pub notify_waiting: bool,
}

#[kernel::task] 生成：静态栈（#[repr(align(8))]）+ 静态 TCB + 入口包装 + 同名构造器（返回未调度的 TaskHandle），再经 kernel::spawn 加入就绪列表。
